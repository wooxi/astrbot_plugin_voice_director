# astrbot_plugin_voice_director

> 🎙️ 专为 **AstrBot** 设计的**多角色自适应音色分发与智能语音导演插件**。全面支持 **BreezeBlue（微风蓝科技）** 官方 API、自定义克隆音色（Voice ID）以及**动态中文情绪标签与口语助词导演**！

---

## ✨ 核心特性 (v1.2.1)

1. **🎭 原生支持 BreezeBlue 声音克隆与动态情绪演播**：
   - 自动识别文本中的官方音频标签（如 `[唱歌]`、`[轻笑]`、`[叹气]`、`[打哈欠]`、`[耳语]`）；
   - 将文本标签与云端 `instructions` 动态融合（如遇到 `[唱歌]` 自动注入旋律感指令），实现极高表现力。
2. **🗣️ 真实人类语气助词规范**：
   - 智能体在对话中自然融入日常口语语气词（啊、呢、哈、呀、欸、嘛、害、咋等），消除机器书面感。
3. **🎯 智能意图 100% 强触发**：
   - 当用户在聊天中表达*“发语音”、“听声音”、“说句话”、“唱首歌”*等明确意图，或智能体回复中带有情绪标签时，**100% 必定生成真实语音条**。
4. **📱 多端平滑自适应**：
   - **飞书端**：下发干净的原生纯语音条，不带多余的重复文字；
   - **微信端**：自动降级为纯文本，确保消息 100% 准确到达不被丢弃。

## 🛠️ 配置说明

| 配置项 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `engine` | string | `breezeblue` | 语音合成引擎（`breezeblue` / `mimo`） |
| `breeze_api_key` | string | `""` | BreezeBlue API Key (`brz_...`) |
| `linwan_voice_id` | string | `voc_yu7t5b4tx7c7` | 林晚专属克隆 Voice ID |
| `linwan_instructions` | text | *见配置* | 林晚语气基础导演指令 |
| `mumu_voice_id` | string | `voc_xy2p77mb2qs6` | 沐沐专属克隆 Voice ID |
| `mumu_instructions` | text | *见配置* | 沐沐语气基础导演指令 |
| `default_probability` | float | `0.4` | 日常闲聊语音触发概率 (0.0~1.0) |
