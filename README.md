# astrbot_plugin_voice_director

> 🎙️ 一个专为 **AstrBot** 设计的**多角色自适应音色分发与智能语音导演插件**。基于小米 **MiMo-V2.5-TTS** 音色设计（Voice Design）接口，让不同的人格智能体拥有真正独特、极具生活呼吸感的专属嗓音！

---

## ✨ 核心特性

1. **🎭 多角色声线自适应**：
   - 自动识别当前说话的人格（如林晚、沐沐）；
   - 根据角色身份，在底层自动注入对应的**专属导演词（Voice Design Description）**，不同智能体发音绝不混淆。
2. **🎯 智能意图强触发**：
   - 当用户在聊天中表达*“发语音”、“听声音”、“说句话”*等明确意图，或大模型回复中带有情绪标签时，**100% 必定生成真实语音条**，拒绝被随机概率误杀。
   - 日常普通闲聊则按可配置概率自然微调，避免每句发语音造成烦躁。
3. **📱 多端平滑自适应**：
   - **飞书端**：只下发干净的原生绿色语音条，绝不附带多余的重复文字；
   - **微信端**：针对微信对话平台不支持原生音频条的特性，自动降级为纯文本，确保消息 100% 准确到达不被丢弃。
4. **🔒 智能心智静默兼容**：
   - 兼容大模型自主选择潜水/静默机制，当智能体决定不回复时自动清空消息链，不产生空包。

---

## 🛠️ 安装方法

1. 将本仓库克隆至 AstrBot 的 `data/plugins/` 目录：
   ```bash
   cd data/plugins/
   git clone https://github.com/wooxi/astrbot_plugin_voice_director.git
   ```
2. 重启 AstrBot。
3. 进入 Web 控制台的「插件」管理页面，可自定义每个角色的声音导演词与默认触发概率。

---

## ⚙️ 配置说明

| 配置项 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `api_key` | string | `""` | 小米开放平台 API Key（留空会自动从 AstrBot 全局配置中回退读取） |
| `api_base` | string | `https://api.xiaomimimo.com/v1` | 小米 API 地址 |
| `linwan_director` | text | *见配置* | 林晚专属音色（清爽平实生活音） |
| `mumu_director` | text | *见配置* | 沐沐专属音色（清亮柔甜治愈音） |
| `default_probability` | float | `0.4` | 日常闲聊语音触发概率 (0.0~1.0) |
